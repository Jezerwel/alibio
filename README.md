# Alibio

Homepage for Alibio, furnished condos for short stays in the Philippines. Each condo links to its Airbnb listing.

## Run it

Static HTML, no build step. Serve the folder and open `index.html`:

```
npx serve .
```

## What is here

- `index.html`: the homepage.
- `credits.html`: photo credits (Wikimedia Commons, CC BY-SA).
- `assets/`: styles, scripts, images and icons.
- `design-system/`: brand tokens (`tokens.json`), brand guide (`README.md`) and component styles (`components.css`).
