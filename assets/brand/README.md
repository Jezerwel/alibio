# Logos

Taken from page 4 of the brand board (Brand Board & Instagram Grid Proposal), as exact vector shapes where the board has them.

- `alibio-lockup.svg`: the secondary logo, the house-and-leaf mark beside the "alíbío" wordmark. Used in the site's nav at 32px tall (28px on a phone).
- `alibio-mark.svg`: the brand mark, the house with the leaf cut out. Used as the favicon and wherever the name is already on screen.
- `alibio-wordmark.svg`: "alíbío" in TT Ramillas with the two tilted i-dots.
- `alibio-arch.png`: the arch of the primary logo. The board holds it only as a picture (748 x 334), so it is a PNG; with "ALIBIO" in TT Ramillas Bold beneath it, it forms the primary logo, used in ivory on the navy footer.

The files are charcoal (#1e1c1c). The site repo also has ivory copies (`-ivory.svg`) for the navy band. Keep clear space of half the mark's height around every logo; never stretch, recolour outside the palette, or set it on a photograph.
